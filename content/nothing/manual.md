## 安装

两种包任选其一，都按当前用户安装或运行，不需要管理员权限：

- **安装版**：双击 `nothing-0.9.11-setup.exe`，确认安装目录后点「安装」。装到 `%LOCALAPPDATA%\Programs\nothing_finder`，会在开始菜单创建快捷方式，并登记到「设置 → 应用」里，可以从那里卸载。
- **绿色版**：解压 `nothing-0.9.11-win64.zip`，双击 `nothing_finder.exe` 即可。

首次启动会在后台给各盘建索引，状态栏显示进度。建完之前也可以搜索，只是结果不全。

## 搜索语法

多个词之间用空格分隔，表示「都要满足」，不加引号的空格就是「与」。

| 写法 | 含义 |
| --- | --- |
| `报告` / `*.log` / `cmd?.exe` | 文件名匹配；含 `*` 或 `?` 时按整名通配 |
| `ext:pdf` / `ext:jpg;png` | 按扩展名，多个用 `;` 分隔，前导点可省 |
| `size:>100mb` `size:<1kb` `size:1mb-100mb` | 按大小，区间包含端点 |
| `path:四川CA` | 在完整路径里匹配 |
| `type:folder` / `type:file` | 只要目录 / 只要文件 |
| `四川\|北京` | 或：含四川或含北京 |
| `!四川\|北京` | `!` 只作用于紧挨着的那一支：不含四川，或含北京 |
| `!!(四川\|北京)` / `!四川 !北京` | 两者都不含 |
| `"a b"` | 引号里算一个整串 |

写错的语法（如空的 `ext:`、`size:abc`）会把提示显示在状态栏末尾，不会静默返回空结果。

## 索引

- 运行中会自动感知文件的增删改名，状态栏显示「增量监视 N 卷」
- 默认每 30 分钟全量重扫一次，状态栏会写明
- 需要立刻重建时按 `F5`，或走菜单「索引 → 重建索引」
- 托盘菜单里可以开启「开机自启动」，开机后最小化驻留，不占桌面

## 托盘

- 点窗口的关闭按钮是收进托盘，不是退出
- 双击托盘图标唤回窗口
- 右键托盘菜单：立即重建索引 / 开机自启动 / 退出

## 卸载

安装版从「设置 → 应用」里卸载；绿色版直接删除解压出来的目录。
